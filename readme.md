# Telegram-бот для поиска фильмов

Этот бот позволяет искать фильмы по названию и рейтингу, просматривать историю поиска и добавлять фильмы в список "Смотреть позже".

## Функционал бота

- Поиск фильма по названию
- Поиск фильмов по жанру и рейтингу
- Просмотр истории поиска
- Просмотр списка "Смотреть позже"
- Отметка фильмов как просмотренных

## Команды бота

- `/start` - запуск бота
- `/help` - справка по использованию
- `/history` - просмотр истории поиска
- `/watch_later` - просмотр списка "Смотреть позже"

## Как использовать бота

1. Запустите бота командой `/start`
2. Используйте кнопки на экране для навигации:
   - `🔎 Поиск` - поиск фильма по названию
   - `🔍 Поиск по рейтингу` - поиск фильмов по жанру и рейтингу
   - `🎬 История поиска` - просмотр истории поиска
   - `📋 Буду смотреть` - просмотр списка "Смотреть позже"

3. При поиске по названию:
   - Введите название фильма
   - Укажите количество результатов (1-10)
   - Просматривайте результаты с помощью кнопок навигации
   - Добавьте фильм в список "Смотреть позже" при необходимости

4. При поиске по рейтингу:
   - Выберите жанр из предложенных
   - Введите рейтинг (например, 7 или диапазон 7-10)
   - Укажите количество результатов (1-10)
   - Просматривайте результаты

5. В истории поиска и списке "Смотреть позже":
   - Просматривайте фильмы с помощью кнопок навигации
   - Отмечайте фильмы как просмотренные
   - Возвращайтесь в главное меню при необходимости

## Требования

- Python 3.8+
- Библиотеки из requirements.txt
- API-ключ сервиса KinoPoisk

## Настройка

1. Создайте файл `.env` в корне проекта
2. Добавьте следующие переменные:
   ```
   BOT_TOKEN=ваш_токен_бота
   RAPID_API_KEY=ваш_api_ключ_kinopoisk
   ```
3. Установите зависимости:
   ```
   pip install -r requirements.txt
   ```
4. Запустите бота:
   ```
   python main.py
   ```
